# Additional comparable games

These are not proposed clones. Each is included because it isolates a question
Voidbound must answer: how to make a base feel alive, how exploration changes
planning, or how a live-service layer can distort a good solo loop.

| Game                       | Why it is comparable                                                                                                           | Useful lesson for Voidbound                                                                                                                    | Evidence                                                                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| State of Survival          | Zombie settlement, survivor characters, world combat, partnerships.                                                            | A settlement and a social war game can share one fiction, but the local campaign must stand before social dependence.                          | Publisher describes rebuilding a safe haven, infected-world combat, and strategic partnerships [S11].                                   |
| Last Fortress: Underground | Shelter layout, specialists such as cooks/engineers/miners, hero squads, outposts, alliance assistance.                        | Make interior layout and crew roles readable; let each new room visibly solve a problem.                                                       | Store description lists customizable rooms, specialist survivors, team composition, outposts, and alliance help [S12].                  |
| Doomsday: Last Survivors   | Shelter + fog map + troops/heroes + tactical/tower-defense encounters.                                                         | A map expedition should have bounded tactical decisions and rewards, not only an asynchronous timer.                                           | Official listing describes shelter building, fog exploration, hero formations, fortifications, troop types, alliances, and raids [S13]. |
| Frozen City                | Primarily solo survival management: worker allocation, health/happiness, production chains, exploration, settlement expansion. | Best control comparison for Phase 3: tension can come from legible needs and tradeoffs, not another player.                                    | Store listing explicitly describes worker needs, production ratios, exploration teams, and expansion [S14].                             |
| Last War: Survival Game    | Base, hero squads, alliances, and an action-forward acquisition hook.                                                          | The first activity needs to be a truthful vertical slice; a compelling mini-mode must feed the main campaign or not be advertised as the game. | Store describes the action opening, base, heroes, and alliances [S16]; players report surprise at the later world/alliance focus [S17]. |

## Adjacent references worth a later dedicated pass

- **Frostpunk / Frostpunk 2:** stronger authored survival consequences,
  expedition storytelling, and difficult-but-readable tradeoffs. Use as a
  qualitative bar for mood and meaningful scarcity rather than a mobile economy
  template.
- **Viking Rise / Lords Mobile / Rise of Kingdoms:** useful later for the
  alliance-territory and map-control questions in Phases 4-6, but not a primary
  Phase 3 reference because their core value is population-dependent.
- **Surviving Mars / The Alters:** useful space-fiction references for a
  functional, inhabited base and expedition narrative; their pacing and platform
  model differ substantially from Voidbound.

## Cross-reference pattern

The mass-market 4X group repeatedly combines a personal settlement, resource
economy, collectible/upgradeable characters, map activity, timed upgrades,
alliance acceleration, and a live event calendar. Frozen City shows which parts
remain engaging when the player is alone: worker needs, production chains,
exploration, and expansion [S14]. That separation is central to Phase 3: build
the latter first, then decide which social systems earn their later complexity.
